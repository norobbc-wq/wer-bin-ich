# Wer bin ich? / من أنا؟

Mindestens 2 Spieler. Eine andere Person bedient das Handy und zeigt die Karte allen außer dem Ratenden. Karten sind Tiere, Gegenstände oder Orte. Stelle Fragen, die nur mit Ja oder Nein beantwortet werden. Richtige Lösung innerhalb der Zeit gibt 1 Punkt. Danach ist der nächste Spieler dran.

لاعبان على الأقل. يتحكم شخص آخر بالهاتف ويعرض البطاقة للجميع ما عدا اللاعب الذي يخمن. البطاقات حيوانات أو أشياء أو أماكن. اطرح أسئلة لا تُجاب إلا بنعم أو لا. يمنح التخمين الصحيح خلال الوقت نقطة، ثم يأتي دور اللاعب التالي.

## Starten / التشغيل

`index.html` öffnen. Keine Installation, kein Build. / افتح index.html. لا يلزم تثبيت.
